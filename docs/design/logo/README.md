## Platz in der Ecke

[agentnook.svg](agentnook.svg)

Kleines Quadrat unten links in einer gepunkteten Begrenzung: ein Agent mit eigenem Platz. Basis ist Tablers `box-align-bottom-left` (filled), MIT-lizenziert; Geometrie unverändert, Farbe auf `#4d9abf` gesetzt, Größe und barrierefreie Beschriftung angepasst.

Das Logo ist ein eigenständiges SVG mit transparentem Hintergrund, ohne Schriften, Rasterbilder, Skripte oder externe Ressourcen. Die Vorschauseite zeigt helle und dunkle Anwendungen sowie Größenproben mit Systemschriften und derselben lokalen SVG-Datei.
